# 요구사항 정의서 · Food Lab (내 냉장고 속 AI 셰프)

SSAFY AI 코어 프로젝트 2회차 · RAG 기반 도메인 지식 서비스
작성일: 2026.10.23

<br>

## 1. 프로젝트 개요

냉장고에 있는 재료나 먹고 싶은 음식을 물어보면, 식품안전나라 공식 레시피와 위키백과 문서에서 근거를 찾아 출처와 함께 답하는 서비스입니다.

레시피는 분량, 재료, 나트륨 같은 숫자가 중요한데 LLM은 이런 걸 그럴듯하게 지어내는 경우가 많습니다. 그래서 공식 레시피 원문과 위키백과에 있는 내용만 가지고 답하고, 없는 건 없다고 말하게 하는 걸 목표로 잡았습니다.

<br>

## 2. 도메인 선정과 조건 충족 근거

정의서 2.1의 도메인 조건 세 가지와 위험 도메인 여부를 이렇게 확인했습니다.

### 2-1. 항목 메타데이터 출처와 건수 (약 100건 이상)

| 항목 | 내용 |
|---|---|
| 출처 | 식품의약품안전처 식품안전나라 Open API `COOKRCP01` (조리식품의 레시피 DB, 공공데이터포털 15060073) |
| 건수 | **1,156건** (2026.10.22 수집, API 응답의 `total_count`와 일치) |
| 주요 속성 | 레시피 번호, 이름, 요리 종류(반찬 574 · 일품 181 · 후식 142 · 밥 119 · 국&찌개 103 · 기타 37), 조리 방법, 재료 원문, 조리 단계(최대 20단계), 열량·탄수화물·단백질·지방·나트륨, 저감 조리 팁, 해시태그, 사진 URL |
| 원본 보관 | `data_check/raw/` 에 받은 그대로 보관하고 읽기만 함 (SHA256 기록) |

### 2-2. 외부 문서 출처와 이용 조건

| 출처 | 이용 조건 | 사용 여부 |
|---|---|---|
| 한국어 위키백과 (MediaWiki API) | CC BY-SA 4.0. 출처 표시와 동일 조건 표시 필요. API 요청 시 User-Agent에 연락처 필요 | 사용 |
| 『우리 몸이 원하는 삼삼한 밥상』 PDF (식약처 발간) | 책자 판권면에는 "무단 복제·광전자 매체 수록 금지", 식약처 저작권 정책에는 "업무상 저작물은 출처 표시 후 이용 가능"이라고 되어 있어 서로 다르게 읽힘 | **이용 조건 확인 전까지 사용 안 함** |

PDF는 54개 레시피의 원문이라는 것까지 PHASE 1-B에서 확인했지만, 이용 조건이 정리되지 않아 색인하지 않았습니다.

### 2-3. 근거 없이 답하면 틀리거나 위험해지는 질문

| # | 질문 | 근거 없이 답하면 생기는 문제 | 근거를 붙이면 |
|---|---|---|---|
| 1 | "두부 달걀전에 달걀은 몇 개 들어가?" | 이름만 보고 "2개" 같은 숫자를 지어냄. 실제 공식 원문 재료에는 달걀이 없음 | 원문 재료 목록 그대로 답하고, 달걀은 원문에 없다고 말함 |
| 2 | "새우 두부 계란찜 1인분 나트륨은?" | 일반적인 계란찜 수치를 추정함. 저염식을 하는 사람에게는 틀린 숫자가 위험함 | 원본 표기 값(99mg)을 그대로, 이상치면 주의 표시와 함께 답함 |
| 3 | "두부 대신 쓸 수 있는 재료는?" | 근거 없는 대체 재료를 제안함. 알레르기나 조리 실패로 이어질 수 있음 | 문서에 있는 내용만 말하고, 없으면 "확인되지 않습니다" |
| 4 | "어린 아이가 먹어도 될까?" | 의학적 판단을 해 버림 | 판단하지 않고, 근거에 있는 영양값·저감 팁만 전하고 면책 안내 |
| 5 | "새우 두부 계란찜을 처음 만든 사람은?" | 그럴듯한 인물이나 유래를 지어냄 | "제공된 문서에서 확인되지 않습니다" (실제 실행으로 확인) |

### 2-4. 위험 도메인 여부와 면책 안내

음식 자체는 금융이나 의료처럼 위험한 도메인은 아니지만, 영양 정보(나트륨, 열량)와 알레르기, 아이·환자 식사 질문이 섞이기 쉬워서 **건강에 인접한 도메인**으로 보고 면책 안내를 넣었습니다.

> 건강·영양 정보는 의료적 조언을 대신하지 않습니다. 알레르기·질환이 있다면 전문가와 상담하세요. 영양 수치는 원본 표기이며 일부 오류가 있을 수 있습니다.

이 문구는 모든 화면 하단에 표시됩니다. 답변 프롬프트에도 "질병 치료·처방·의학적 판단은 하지 않는다"를 넣었습니다.

## 6. F2004를 부분 충족으로 적은 이유

식품안전나라 레시피는 대부분 "미역 닭가슴살전" 같은 창작 메뉴 이름이라, 위키백과에 레시피 자체를 다룬 문서가 거의 없습니다. 수집 장치(레시피 이름 항상 검색, 같은 제목 문서 강제 포함)는 동작하지만, 실제로는 재료·조리법 문서가 주로 근거가 됩니다.

이 경우 화면에 "레시피 자체를 다룬 외부 문서 없음 — 레시피 메타데이터와 원문 링크만 항목 근거"라고 표시하고, 완전 충족으로 보고하지 않았습니다. 『삼삼한 밥상』 PDF 이용 조건이 확인되면 54개 레시피는 원문 근거를 붙일 수 있습니다.
